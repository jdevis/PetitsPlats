# Les Petits Plats

Project 07 [Openclassrooms React application developer training course](https://openclassrooms.com/fr/paths/2288-developpeur-dapplication-react)
Develop a search algorithm in JavaScript

## 🚀 Features

Develop an efficient search algorithm for a cooking recipe platform.

-   Design the site's user interface using a front-end framework.
-   Develop two versions of a search algorithm with filters using a JSON file.
-   Analyze and compare their performance with Jsben.ch and identify the most efficient algorithm.
-   Address the principles of Green Code
